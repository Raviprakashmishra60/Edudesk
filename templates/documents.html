Document Center

Prepare photos, signatures and PDFs for online forms. Everything runs inside your browser — your files are never uploaded or stored.

PDF tools need the pdf-lib library from the internet (cdnjs). Check your connection and reload this page.

Image resize & compress

Set a size in pixels and/or a maximum file size. Leave a field empty to skip it.

Image to PDF

Select one or more images. Each image becomes one PDF page, in the order you pick them.

PDF merge

Select two or more PDFs. They are joined in the order you select them.

PDF split

Enter page ranges separated by commas. Each range becomes its own PDF. Example: 1-2, 3, 4-6

PDF compress

Re-saves the PDF with an optimised structure. This helps text-based PDFs; PDFs full of large scanned images may not shrink much. For those, reduce the images first (use the image tool) and then use Image to PDF.

File size checker

Check whether a file fits the size limit mentioned in the form's notification.

Photo & signature requirements guide

Every form has its own rules. The numbers in the official notification always win — this guide only helps you prepare.

  • Read the notification first and note the exact size in KB, dimensions in pixels, and format (JPG / PNG / PDF).
  • Photo: recent, plain light background, face clearly visible, no filters, no sunglasses or cap unless allowed.
  • Signature: sign with a dark pen on plain white paper, scan or photograph in good light, then crop tightly.
  • Dimensions: use the Image tool to set the width and height asked in the form.
  • File size: use "Max size (KB)" in the Image tool, then confirm in the File size checker.
  • Certificates: scan flat and straight; merge several pages into one PDF if the form wants a single file.
  • Before uploading: open the final file once to be sure it is clear and not cut off.
  • Privacy: do not share your documents on random websites. This page keeps files on your device.
